# Synthara Overview

Synthara helps academic and technical researchers move from a broad question to a structured, cited draft.

## Problem

Research workflows often split across search engines, paper databases, note-taking tools, citation managers, writing apps, and AI chats. That makes it hard to preserve source context, compare evidence, and produce a clean document with reliable citations.

## Product

Synthara combines:

- Source discovery across web, academic, and code repositories.
- A source library with normalized metadata and credibility signals.
- A dual-pane workspace with a document editor and an AI assistant.
- Citation formatting through a format-agnostic internal model.
- Export to DOCX, PDF, and Markdown.

## Primary Users

- Students writing research reports.
- Technical writers preparing evidence-backed documents.
- Founders and analysts collecting market or technical evidence.
- Engineers researching APIs, repositories, and implementation patterns.

## MVP Outcome

The MVP should let a user enter a research topic, collect sources, ask the assistant questions about those sources, generate a structured outline, draft sections, and export the result with a bibliography.

## Current Foundation

The repository currently contains a Next.js application shell, a Gemini-backed AI API route, a Contentstack Delivery API helper, and planning docs for the full SaaS build.
